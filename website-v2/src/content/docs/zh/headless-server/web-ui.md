服务器跑起来后(见[服务器部署](/docs/zh/headless-server/setup/)),在浏览器里打开它的地址即可,例如 `http://<host>:17800/`。它沿用桌面客户端的布局与任务操作方式,并针对远程使用和窄屏做了适配。

Web 界面通过 agent 的 `/rpc` WebSocket(JSON-RPC)管理下载,不使用 aria2 的 `/jsonrpc`。页面与服务器同源,所以不需要填写服务器地址。

## 登录

### 首次运行:设置访问密钥

服务器尚未设置访问密钥时,任何地址都会跳转到初始化卡片。

![首次运行初始化卡片:初始化口令、新访问密钥、确认访问密钥和「随机生成」按钮](/docs/web-ui/setup.zh.webp)

1. **初始化口令**--一次性口令,用来证明你能控制这台服务器。从 agent 数据目录的 `setup-bootstrap` 文件读取(Docker 为 `/data/agent/setup-bootstrap`);NAS 套件则在下载共享文件夹的 `FluxDown-setup-code.txt` 中。它不是访问密钥。
2. **新访问密钥**与**确认访问密钥**--自己输入,或点**随机生成**。请妥善保存,每个浏览器登录都要用。
3. 点**保存并继续**。

访问密钥为 8 到 128 位可见 ASCII 字符(不含空格),至少包含一个字母和一个数字。口令错误会被拒绝,错误次数过多会锁定初始化几分钟。如果密钥已在别处设置好,页面会提示直接登录。

设置密钥之前,`/download*` 与 `/jsonrpc`(POST/WS)返回 403,所以 aria2 客户端和油猴脚本不能抢在你之前接管服务器。初始化页面与对应接口仍可访问。

### 登录

![登录卡片:访问密钥输入框和「记住此设备」复选框](/docs/web-ui/login.zh.webp)

输入**访问密钥**并点**登录**。眼睛按钮可显示或隐藏输入内容。密钥错误或不符合密钥规则时提示「访问密钥无效」。如果服务器仍需初始化,页面会带你回到初始化卡片。

**记住此设备**决定密钥保存在本浏览器的哪里:

| 状态 | 存储位置 | 有效期 |
|---|---|---|
| 勾选(默认) | `localStorage` | 浏览器重启后依然有效 |
| 不勾选 | `sessionStorage` | 关闭标签页即清除 |

密钥只会发给服务器本身。要退出,打开**设置 -> API 服务**,点**退出此浏览器的登录**下的**退出登录**;这会清除浏览器里保存的密钥并回到登录页。在服务器上改了密钥后,浏览器里存的那份会就地更新,并保留你的「记住」选择。

初始化时设置的密钥同时就是**设置 -> API 服务**里的**访问令牌**。预设或强制指定密钥的环境变量见[服务器部署](/docs/zh/headless-server/setup/)。

## 主界面布局

![Web 界面主界面:活动栏、侧边栏、工具栏、任务列表和状态栏](/docs/web-ui/main.zh.webp)

- **活动栏**(最左)--**下载**、**RSS 订阅**与**推送通知**页面;底部是账户入口和**设置**。插件可以添加自己的入口。
- **侧边栏**--**状态**文件夹、**队列**,以及可选的**设备**。详见下文。
- **标题栏 / 工具栏**--**新建任务**、**全部暂停**、**全部恢复**、**失败重试**、搜索框和**视图**按钮。右侧的圆点显示连接状态。
- **任务列表**--每个任务一行,选中任务后可打开详情面板。
- **状态栏**--总下载 / 上传速度、下载 / 上传限速、代理选择器和版本号。有更新时可点版本号。

在工具栏或活动栏上点右键,选**自定义布局…**,可以把条目在标题栏、活动栏和状态栏之间拖动,或隐藏它们;**恢复默认布局**可还原。这里还有「剩余空间」条目,默认隐藏。

### 侧边栏

**状态**文件夹包含**全部**、**未完成**、**已完成**、**做种中**、**失败**和**已暂停**,各带实时计数。只有**全部**下嵌套分类子项(视频、音频、文档、图片、程序、压缩包、其他,以及你自己的分类),没有单独的「分类」分区。在分类子项上点右键即可新建或编辑分类。

**队列**列出内置的**主队列**与**稍后下载**,以及你创建的队列。**队列**标题旁的齿轮打开队列管理,在里面用**新建队列**创建队列。在队列上点右键打开菜单:

- **启动队列** / **停止队列**--停止会暂停其中全部任务并阻止它们被自动启动;启动则按队列内顺序恢复。主队列始终运行,不能停止。
- **管理队列**--修改队列名称、默认保存目录、**最大同时下载数**和限速。**启用每日定时**后可设置**启动时间**与**停止时间**(可只填一个),并在**重复**里选择生效的星期。主队列不能设置定时,内置队列不能重命名。
- **删除队列**--被删队列里的任务会移回主队列。

侧边栏哪些分区、活动栏哪些入口可见,由**设置 -> 通用**控制(**显示状态**、**显示队列**、**显示分类**、**显示设备协同**以及活动栏入口)。

### 窄屏

宽度不超过 820 px 时,活动栏变成底部标签栏,侧边栏和详情面板以抽屉方式打开,对话框全屏显示,列表变为卡片。功能保持一致。

## 查找与整理任务

### 搜索

在搜索框里输入即可按名称过滤。在页面任意位置按 `Ctrl+F`(macOS 为 `Cmd+F`)或 `/` 跳进搜索框,`Esc` 清空。搜索与侧边栏的状态、分类、队列组合生效。

### 视图菜单

![视图菜单:列、分组、排序、显示四个标签页,以及带拖动手柄的列勾选列表](/docs/web-ui/view-menu.zh.webp)

**视图**按钮打开一个含四个标签页的浮层:

| 标签页 | 作用 |
|---|---|
| **列** | 勾选显示或隐藏列,拖动手柄调整顺序。可选列:**文件名**、**进度**、**大小**、**速度**、**剩余时间**、**状态**、**创建时间**、**协议**、**来源**、**队列**。至少保留一列。**重置为默认列**恢复默认组合。 |
| **分组** | **不分组**、**状态**、**日期**、**类型**、**队列**、**站点**、**目录**、**剧集名称**。 |
| **排序** | **智能**、**创建时间**、**名称**、**大小**、**进度**、**速度**、**状态**,配合**升序**或**降序**(智能排序无方向)。 |
| **显示** | 行密度(**紧凑**、**舒适**、**宽松**)、表头对齐,以及**详情面板**:显示或隐藏,位置在**底部**或**右侧**。 |

视图偏好保存在服务器的 `desktop.downloads.view` 偏好里,换浏览器也会保留。

### 选择多个任务

点击任务即选中;Ctrl/Cmd 点击切换单个,Shift 点击选择区间。`Ctrl+A`(`Cmd+A`)全选,`Esc` 清除选择。选中一项或多项后,一个操作条会取代列标题(窄屏为浮动条),显示**已选 {n} 项**和这些操作:**继续**、**暂停**、**下载文件**(仅已完成任务)、复制任务信息、**导出任务信息（.txt）**、删除、取消全选。

删除按钮提供**删除任务**(保留文件)与**删除任务和文件**(会先确认)。键盘上,`Delete` 删除所选任务但保留文件,`Shift+Delete` 会询问是否连同文件一起删除。

批量暂停、恢复、删除会用一次 `daemon.task.pauseMany`、`resumeMany` 或 `deleteMany` 调用发送整组 ID。daemon 会对 ID 去重并忽略未知 ID。

## 任务操作

![任务右键菜单:暂停、优先下载、打开所在文件夹、编辑任务、移动到队列、选择、删除任务和详情](/docs/web-ui/context-menu.zh.webp)

在任务行上点右键查看可用操作。出现哪些项取决于任务的状态和类型:

| 分组 | 菜单项 |
|---|---|
| 运行 | **继续** / **暂停**(做种中的 BT 任务为**继续做种** / **停止做种**),**优先下载** / **取消优先**(暂停其他任务,把带宽让给该任务;它完成后其他任务自动恢复) |
| 文件 | **下载文件**(把已完成的文件发到浏览器)、**打开文件**、**打开所在文件夹**、**复制文件** |
| 编辑 | **重命名**、**更换链接**、**编辑任务**、**修改线程数**、**完整性校验**、**重新下载** |
| BitTorrent | **选片方式**(最稀有优先、按顺序下载、先下载首尾文件块)、**强制重新校验**、**移动到…**、**任务限速…**、**添加 HTTP 源…**、**超级做种**、**复制磁力链接**、**导出 .torrent 文件…** |
| 其他 | **复制下载地址**、**移动到队列**、**选择**、**全选**、插件命令、**删除任务**、**删除任务和文件**、**详情** |

**打开文件**、**打开所在文件夹**和**复制文件**作用于 agent 所在的机器。只有连接允许时才会出现,通常是浏览器与 agent 在同一台机器上;访问远程服务器时不会提供。

|---|---|
| **常规** | 状态、大小、已下载、速度、剩余时间、开始与结束时间、保存路径、队列、代理、哈希校验,以及**来源构成**环形图(数据来自源站、多 CDN 节点、智能代理、多网卡各占多少)。条件允许时,按钮可复制链接、编辑任务、更换链接或修改线程数。 |
| **速度** | 实时速度曲线,以及当前、平均、峰值速度、下载用时和预计剩余时间。 |

| **高级** | 单任务的高级信息,例如代理与请求选项。 |

BitTorrent 任务另有**文件**、**做种中**、**Tracker**和**连接**标签页;eD2K 任务另有**来源**和**网络**。

## 新建下载

点工具栏的**新建任务**,或把链接、`.torrent` 文件、包含链接的 `.txt`、`.url`、`.list` 文件拖到页面上。

![新建下载对话框:三条已粘贴的链接、范围提示、导入按钮、带分类选择器的保存目录和线程数](/docs/web-ui/new-task.zh.webp)

每行粘贴一个链接(HTTP、FTP、磁力)。右上角的计数显示识别到的链接数。连续编号的文件可以在文件名中手写范围,例如 `https://example.com/comic/[001-215].webp`,下方会预览首尾结果。

| 控件 | 说明 |
|---|---|
| **打开种子文件** | 从你的电脑选择 `.torrent`,浏览器会把它上传到服务器。 |
| **做种本机文件** | 用已有文件生成种子并做种。 |
| **导入 TXT 文件** | 把文本文件里的链接读入输入框。 |
| **保存目录** | 左侧下拉:**自动分类**(按文件类型选分类目录)、**不分类**或指定分类;右边是目录路径和**浏览**,浏览列出的是**服务器**上的目录,不是你电脑上的。在**设置 -> 下载**里开启后,会记住最近用过的目录。 |
| **重命名** | 仅单个链接可用;留空则自动识别文件名。 |
| **线程数** | **自动**、4、8、16、32、64 或**自定义**。 |

`Ctrl+Enter`(`Cmd+Enter`)可提交对话框。

![新建下载对话框展开高级选项:任务代理、用户代理与管理预设、Cookie](/docs/web-ui/new-task-advanced.zh.webp)

**高级选项**包含**HTTP 认证**(仅单个非磁力链接)、**任务代理**(**跟随全局**使用代理模式与站点规则;选其他任何项,该任务都会忽略站点规则)、**用户代理 (User-Agent)**与**管理预设**、**Cookie**、**来源页（Referer）**、**哈希校验**、**自定义请求头**以及**忽略 HTTPS 证书错误**。

底部按钮:

- **导出任务信息（.txt）**--把填写的任务保存为文本文件。
- **下载 {n} 个文件**(单个链接时为**开始下载**)--创建并启动任务。点箭头可选择队列。
- **稍后下载**--创建任务但不开始,放入**稍后下载**或你从箭头里选的队列。

任务通过 agent 的 `/rpc`(`daemon.task.create` 与 `createMany`)直接创建,没有额外的确认提示,因为你已经处在已认证的会话里。

### HLS 画质与文件选择

有些下载在准备阶段需要你做决定。询问经 WebSocket 下发,所以只有 Web 界面已打开并连接时才会弹出对话框:

- **选择画质**--HLS(M3U8)播放列表有多个版本时,列出供你选择。
- **选择要下载的文件**--多文件种子或磁力链接会列出文件及大小,带**筛选文件…**输入框,确认按钮上显示已选文件数与总大小,方便跳过不需要的文件。

60 秒内无人回答时,引擎采用默认值(最佳 HLS 版本,或全部种子文件)并关闭对话框。对种子任务,可在**设置 -> BitTorrent**关闭**文件选择 60 秒后自动选择默认项**,让对话框一直等待,任务会停留在「准备中」。没有打开任何 FluxDown 窗口或网页时,会立即下载全部文件。

## 取回已完成文件

已完成的文件保存在服务器上。要拷到你的电脑,用右键菜单或选择操作条里的**下载文件**。浏览器通过 `GET /api/web/files/tasks/{id}` 下载,保留原文件名。浏览器发起的下载不能带自定义请求头,所以请求用 `?token=` 查询参数携带访问密钥;密钥缺失或错误返回 401,返回 503 表示下载服务离线。磁盘上文件已丢失的任务不能这样下载。一次选多个文件时,每个间隔 0.4 秒依次触发。

### API 服务

![API 服务页:监听端口、aria2 RPC、MCP 与管理 API 地址、访问令牌和功能开关](/docs/web-ui/settings-api.zh.webp)

服务器模式下,监听地址与端口由环境变量 `FLUXDOWN_BIND` 决定,页面只读显示。页面列出可复制的地址:**aria2 RPC 兼容**(`/jsonrpc`)、**MCP 端点**(`/mcp`)和**管理 API**(`/api/v1`)。**访问令牌**一行可查看、复制、修改或重新生成访问密钥(规则与初始化相同)。**功能开关**控制**浏览器脚本接管**、**aria2 RPC 兼容**、**管理 API**、**MCP 端点**,以及跨域访问(CORS)。

### 语言

Web 界面已本地化。语言取第一个有设置的来源:agent 偏好 `general.locale`(**设置 -> 外观 -> 语言**;选**跟随系统**则看下一个来源),然后是服务器的 `FLUXDOWN_LANG` 环境变量,最后是浏览器语言。登录与初始化页在登录前读不到该偏好,所以使用 `FLUXDOWN_LANG` 或浏览器语言,并在浏览器里缓存最近一次解析出的语言。

## 连接状态与断线重连

标题栏的圆点显示链路状态,不健康时任务列表上方还会出现横幅:

| 状态 | 含义 |
|---|---|
| 正在连接 / 已连接 | 正在建立 WebSocket / 工作正常。 |
| 重连中 | 连接已断开。下载仍在服务器上运行;横幅倒计时下一次尝试,并显示第几次。 |
| 服务器的下载服务已离线 | 网页连接正常,但恢复前无法操作任务。 |
| FluxDown 服务已停止 / 不兼容 | 服务已停止,或网页界面版本与服务器不匹配。 |

重连使用指数退避:从 0.5 秒开始每次翻倍,上限 15 秒,并带约 ±20% 的随机抖动。服务器提示事件流落后时,客户端会更快重连(从 250 毫秒起,上限 3 秒)。点**立即重试**可跳过等待。连接恢复后,实时进度、速度和日志会自动继续,不需要刷新页面。
