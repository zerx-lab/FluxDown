主窗口由五个区域组成:活动栏、侧边栏、工具栏、任务列表和状态栏。需要时,详情面板会在任务列表区域内打开。

![FluxDown 桌面端主窗口,带编号标注:活动栏、侧边栏、工具栏、任务列表、状态栏](/docs/desktop/main-window-annotated.zh.webp)

1. **活动栏** - 在各页面(下载、RSS 订阅、推送通知)之间切换;账户和**设置**位于底部。
2. **侧边栏** - 按状态、分类和队列筛选任务列表。
3. **工具栏** - 新建任务、任务操作、搜索和**视图**菜单。
4. **任务列表** - 每个任务一行。
5. **状态栏** - 实时速度、限速、代理、电源菜单和版本号。

## 活动栏

最左侧的窄图标列:

- **下载** - 即本文介绍的页面。
- **RSS 订阅**和**推送通知** - RSS 订阅与推送通知渠道。两者都可以在**设置 → 通用 → 活动栏**中隐藏。
- **账户**和**设置** - 位于活动栏底部。

## 侧边栏

侧边栏包含**状态**文件夹和**队列**区块。点击条目即可筛选任务列表,每个条目都显示实时任务数。

- **全部** - 所有任务。点击展开嵌套在它下面的分类子项:视频、音频、文档、图片、程序、压缩包、其他,以及你的自定义分类。只有**全部**会嵌套分类,没有单独的「分类」区块。右键分类可**编辑分类**或**添加分类**。
- **下载中**、**已完成**、**做种中**、**失败**、**已暂停** - 每种状态一个条目。做种中的任务同时计入已完成。
- **主队列**、**稍后下载**以及你创建的队列。**队列**区块里的管理按钮可打开队列管理窗口;右键队列可选择**启动队列** / **停止队列**、**管理队列**和**删除队列**。详见[快速上手](/docs/zh/getting-started/quickstart/#队列与限速)。
- 只有账户下链接了其他设备时,才会出现**设备**区块。

右键区块标题并选择**隐藏此区块**,或在**设置 → 通用 → 侧边栏显示**中管理。工具栏的侧栏按钮可收起 / 展开侧边栏;拖动它的边缘可调整宽度。

## 工具栏

从左到右:

- **侧栏按钮** - **收起侧栏** / **展开侧栏**。
- **新建任务** - 打开「新建下载」窗口。在布局编辑模式(见下文)中,它可以显示为图标或带文字的按钮。
- **清除已完成任务** - 把已完成的任务从列表中清除。
- **更多操作** - **清理无效任务**和**清理所选的暂停或失败任务**。
- **全部暂停**、**全部恢复**、**失败重试**。
- **搜索任务...**(<kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>F</kbd>) - 输入时实时筛选列表。若要搜索功能与设置,请按 <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>K</kbd>。
- **视图** - 列、分组、排序和显示选项。

## 任务列表

每一行显示文件名,下方是分类与来源站点,然后是你启用的列。默认列为**文件名**、**大小**、**进度**、**状态**(速度、剩余时间、已下载 / 总大小)和**创建时间**。若想隐藏来源站点,请在**设置 → 通用**中开启**隐藏任务来源**。

- **选择** - 点击一行;<kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+点击切换单行,<kbd>Shift</kbd>+点击选择范围。选中多行后,选择栏会显示**已选 {n} 项**以及批量操作:暂停 / 继续、打开文件 / 文件夹、**复制任务信息**、**导出任务信息(.txt)**、删除和**取消全选**。
- **双击** - 已完成的任务会打开文件,其他任务则打开详情面板。
- **悬停操作** - 指针悬停在一行上时,行右端会显示暂停 / 继续(失败任务为重试)、打开文件、打开所在文件夹和**详情**。
- **右键** - 上下文菜单。菜单项取决于任务类型与状态:**暂停** / **继续**、**优先下载** / **取消优先**、**打开文件**、**打开所在文件夹**、**复制文件**、**重命名**、**更换链接**、**编辑任务**、**完整性校验**、**重新下载**、**移动到队列**、**复制下载地址**、**选择**、**全选**、**删除任务**、**删除任务和文件**以及**详情**。

## 视图菜单

工具栏的**视图**有四个页面。**列**页面列出所有列,每项带复选框和拖动手柄;拖动可调整顺序,**重置为默认列**可恢复默认。可选列:**速度**、**剩余时间**、**协议**、**来源**、**队列**。

| 页面 | 选项 |
|---|---|
| **列** | 显示、隐藏和调整列的顺序。 |
| **分组** | **不分组**、**状态**、**日期**、**类型**、**队列**、**站点**、**目录**、**剧集名称**。 |
| **排序** | **智能**、**创建时间**、**名称**、**大小**、**进度**、**速度**、**状态**,可选**升序**或**降序**。 |
| **显示** | **密度**(**舒适** / **紧凑** / **宽松**)、**表头对齐**,以及**详情面板**:**显示详情面板**,并可选**底部**或**右侧**位置。 |

点击分组标题可折叠该分组。截图展示的是**分组 → 状态**。

![任务列表按状态分为下载中、错误、已暂停、已完成四个分组](/docs/desktop/group-by-status.zh.webp)

## 详情面板

选中任务后按 <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>I</kbd>,或在右键菜单中选择**详情**,即可打开面板。默认停靠在底部;可在**视图 → 显示**中改为右侧。面板里的按钮可把它弹出为独立窗口。未选中任何任务时,面板显示**选择一个任务查看详情**。

HTTP 任务有以下标签页:

- **常规** - 状态、大小、已下载、速度、剩余时间、保存路径、线路和来源构成。
- **速度** - 速度曲线,含当前、平均和峰值速度。
- **日志** - 任务的活动事件(重试、分段拆分、CDN 与网络事件)。
- **高级** - 任务使用的代理线路和 TLS 选项。

BitTorrent 任务会增加**文件**、**做种中**、**Tracker**和**连接**标签页;eD2K 任务有各自的来源与网络标签页;插件还可以贡献更多标签页。

## 状态栏

状态栏位于窗口底部。

![状态栏及七个编号标注:下载速度、上传速度、下载限速、上传限速、代理、电源菜单、版本号](/docs/desktop/statusbar.zh.webp)

1. **下载速度** - 所有任务的总速度。
2. **上传速度** - 总上传速度(BitTorrent)。
3. **下载限速** - 点击可选择**无限制**、预设值(1、5、10 或 50 MB/s)或**自定义**。最近使用的自定义值会列出,可通过**清除最近记录**清空。
4. **上传限速** - 选项相同;限制 BitTorrent 上传速度,含做种。
5. **代理** - 在**不使用代理**、**系统代理**、**手动配置**和**自动(推荐)**之间切换。若尚未配置代理,会提示你先到**设置**中配置。
6. **电源菜单**(**定时电源操作**) - 选择**关机**、**睡眠**或**退出 FluxDown**,再选择时机:**完成后立即**、1 / 5 / 10 / 30 分钟后、**自定义**,或**持续低速时执行电源操作**。启用后状态栏会显示倒计时;点击它(或使用托盘菜单)即可取消。
7. **版本号** - 当前安装的版本;有可用更新时,更新提示会出现在这里。

**剩余空间**读数可用,但默认隐藏(见下文布局编辑)。

## 主题

在**设置 → 外观 → 主题模式**中选择**亮色**、**暗色**或**跟随系统**。命令面板(<kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>K</kbd>)里也有**切换主题**。

![暗色主题下的 FluxDown 主窗口](/docs/desktop/dark-theme.zh.webp)

## 自定义布局

右键工具栏、活动栏或状态栏,选择**自定义布局…**。拖动条目可调整顺序,或在标题栏、活动栏和状态栏之间移动;点击条目上的眼睛图标可隐藏或显示。**恢复默认布局**还原默认设置,**完成**退出编辑模式。

## 系统托盘

开启**关闭时最小化到托盘**(默认开启)后,关闭窗口会让 FluxDown 继续在托盘中运行。左键点击托盘图标可恢复窗口,右键则弹出菜单:

- **显示主窗口**
- **全部暂停**、**全部恢复**
- **设置**
- **重启**
- **退出** - 退出 FluxDown。

已启用定时电源操作时,菜单中还会出现**取消定时关机**(或睡眠 / 退出)。
