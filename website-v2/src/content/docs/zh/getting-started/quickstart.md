本文带你走完在 FluxDown 中新建下载、控制运行中任务、用队列与限速组织任务的完整流程。如果还没安装,先看[安装](/docs/zh/getting-started/installation/);想了解各区域的具体位置,可参考[界面总览](/docs/zh/getting-started/interface/)。

## 创建第一个下载任务

点击工具栏的**新建任务**,或按 <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>N</kbd>,打开**新建下载**窗口。

![新建下载窗口,已粘贴三个链接:zip、mp4 和磁力链接](/docs/desktop/new-download.zh.webp)

窗口中的字段,从上到下:

| 字段 | 说明 |
|---|---|
| **下载链接** | 每行一个链接。支持 HTTP、FTP 和磁力链接;右上角会实时显示 **N 个链接**。连续编号的文件可在文件名中手写范围,例如 `https://example.com/comic/[001-215].webp`。展开后超过 1000 个链接的范围会被拒绝。 |
| **打开种子文件** / **导入 TXT 文件** | 选择本地 `.torrent` 文件,或从文本文件中导入链接列表。 |
| **保存目录** | 文件的保存位置。左侧的选择器可选**自动分类**(按文件类型自动选择分类目录)、**不分类**或某个具体分类;**浏览**打开文件夹选择窗口。默认目录取自**设置 → 下载**;若开启**跟随上次保存位置**,则使用上次的目录。 |
| **线程数** | **自动**、预设值(4、8、16、32、64)或**自定义**(最大 512)。超过 64 时会出现被限速或封 IP 的风险提示。磁力链接不显示此项。 |
| **重命名(可选,留空自动识别)** | 覆盖自动识别的文件名。仅在只有一个链接时显示。 |

点击**高级选项**可仅对这些任务覆盖设置;留空的项沿用全局设置。

| 选项 | 说明 |
|---|---|
| **任务代理** | **跟随全局**(代理模式与站点规则)、**直连(不使用代理)**、**系统代理**、**手动代理(全局配置)**,或**自定义…**并填写如 `socks5://127.0.0.1:1080` 的地址。除**跟随全局**外,其他选择都会让该任务忽略站点规则。 |
| **User-Agent** | 预设(**默认(FluxDown)**、**Chrome**、**Firefox**、**Edge**、**Safari(macOS)**)或**自定义**。**管理预设**可编辑你自己的列表。 |
| **Cookie** | 原始的 `name=value; name2=value2`,用于需要登录的下载。 |
| **来源页(Referer)** | 要发送的 Referer 请求头。 |
| **哈希校验** | 选择算法并填写期望的哈希值,下载完成后校验文件。 |
| **自定义请求头** | 以名称 / 值的行添加额外 HTTP 请求头(**添加请求头**)。 |
| **HTTP 认证** | 用户名和密码;**为此网站保存**会记住它们。仅单个链接时显示。 |
| **忽略 HTTPS 证书错误** | 对这些任务接受无效证书。 |

当从浏览器捕获的链接已带有 HTTP 认证时,窗口会给出提示;在 **HTTP 认证**中填写用户名即可改用你自己的凭据。

底部按钮:

- **下载 N 个文件**(单个链接时为**开始下载**) - 创建任务并立即开始。任务进入侧栏当前选中的队列,否则进入**默认下载队列**(**设置 → 下载**),再否则进入**主队列**。
- **稍后下载** - 只创建任务、不开始,任务放入内置的**稍后下载**队列。
- 两个按钮右侧的箭头会列出你的队列,选择其中一个即立即提交到该队列。
- **导出任务信息(.txt)** - 输入多个链接时显示;把解析出的列表保存为文本文件。
- **取消** - 关闭窗口。

## 任务控制

- **双击**一行 - 已完成的任务打开文件,其他任务打开详情面板。
- **悬停操作** - 行右端会出现暂停 / 继续、打开文件、打开所在文件夹和**详情**;失败的任务显示重试按钮。
- **右键**一行打开完整菜单:**暂停** / **继续**、**优先下载**、**打开文件**、**打开所在文件夹**、**复制下载地址**、**移动到队列**、**删除任务**、**删除任务和文件**等。菜单项取决于任务状态和协议。
- **同时操作多个任务** - <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+点击或 <kbd>Shift</kbd>+点击选择多行,按 <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>A</kbd> 全选,或在菜单中选择**选择**。随后选择栏提供暂停 / 继续、打开、**复制任务信息**、**导出任务信息(.txt)**、删除和**取消全选**。<kbd>Space</kbd> 暂停或继续所选任务;<kbd>Esc</kbd> 清除选择。
- **一次操作全部任务** - 工具栏的**全部暂停**、**全部恢复**和**失败重试**。**全部恢复**会跳过已停止的队列。

### 编辑任务属性

在任务右键菜单中选择**编辑任务**,可修改保存目录、下载限速、连接设置、用户代理、请求头、Cookie、认证引用、分类、标签和一次性计划开始时间。URL 只读;要替换来源请使用**更换链接**。

连接相关设置会立即让活动任务重新连接,不支持续传的来源可能重新开始。文件设置变更时,任务会暂停、移动并恢复。Cookie 只写不读:配置后不会再显示,只能用**清除 Cookie**清除。任务不支持的属性会给出提示,而不会被修改。

## 队列与限速

状态栏有两个限速项:**下载限速**和**上传限速**。点击后可选择**无限制**、预设值(1、5、10 或 50 MB/s)或**自定义**。上传限速作用于 BitTorrent 上传,含做种。两者默认都是无限制。

每个任务都属于一个队列,内置两个:

- **主队列** - 新下载默认进入这里,除非你选了其他队列。它始终运行,不能停止、定时、重命名或删除。
- **稍后下载** - **稍后下载**按钮把任务放在这里。它不能重命名或删除。

### 创建与编辑队列

点击侧栏**队列**区块里的管理按钮,或右键队列选择**管理队列**,打开队列管理窗口,选择**新建队列**即可添加。每个队列有:

- **队列名称**(内置队列不可修改)
- **下载限速**和**上传限速**
- **最大同时下载数**(0 = 不设队列上限,全局上限仍然生效)
- **线程数量**(0 = 自动)
- **默认保存目录**
- **默认 User-Agent**

点击侧栏中的队列可把任务列表筛选到该队列。要移动已有任务,右键它并选择**移动到队列**。删除自定义队列时,其中的任务会移至主队列。

### 启动与停止队列

队列处于**运行中**或**已停止**状态。在侧栏右键队列,或使用队列管理窗口里的按钮:

- **停止队列**会停止该队列。已停止的队列会被**全部恢复**和定时计划跳过,**全部恢复**会提示你先启动该队列。
- **启动队列**会继续该队列中未完成的任务。

这让队列成为一组下载的一键开关。可以把批量下载放在单独的队列里,或把任务先放进**稍后下载**,晚上再启动该队列。

### 每日定时

在队列管理窗口中,为自定义队列或**稍后下载**开启**启用每日定时**。设置开始时间、停止时间或两者都设(留空的一侧不触发),并在**重复**下选择星期。到达设定时间时,队列会像你点击了按钮一样启动或停止。电脑睡眠期间错过的时间点,会在当天唤醒后补触发。

### 并发上限

**设置 → 下载**里的**最大同时下载数**(默认 5)限制所有队列的运行任务总数,除非某个队列设置了自己的上限。

## Boost:优先下载

急需某个文件?右键未完成的任务,选择**优先下载**。FluxDown 会暂停其他活动和排队的任务,让该任务独享带宽,并给它加上闪电图标。它完成或停止后,被暂停的任务会按顺序恢复。选择**取消优先**可手动解除。已完成和失败的任务不能优先下载,失败的任务请先重试。

## 下载完成后

在**设置 → 通知**中可以控制任务完成后的行为:

- **完成通知** - 系统通知。
- **显示下载完成窗口** - 弹出带**打开文件**和**打开所在文件夹**的窗口,只对你发起的下载生效,且正在查看主界面时不弹。
- **显示下载进度窗口** - 在未查看主界面时新建下载,会打开独立的进度窗口且不抢焦点。关闭窗口不影响下载。

你也可以随时双击已完成的任务打开它,或右键选择**打开文件** / **打开所在文件夹**。
