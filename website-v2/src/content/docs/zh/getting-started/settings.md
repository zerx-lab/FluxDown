点击活动栏底部的齿轮打开**设置**,或按 `⌘ ,` / `Ctrl ,`。窗口左侧是分类列表,上方是搜索框,右侧是所选分类的页面。本页按同样顺序说明。

![FluxDown 桌面端设置窗口:左侧为搜索框与分类列表,右侧为常规页面](/docs/desktop/settings-general.zh.webp)

分类依次为**常规**、**账户**、**外观**、**快捷键**、**下载**、**BitTorrent**、**eD2K**、**代理**、**API 服务**、**通知**、**扩展**、**诊断**和**关于**。账户对你开放**推介有奖**时,该页会出现在**账户**之后。

在搜索框输入名称即可筛选设置项:匹配的分类和设置行保留,其余隐藏。

下表默认值为全新安装时的值,大多数设置即时生效。[无头 Web UI](/docs/zh/headless-server/web-ui/) 提供相同的页面,但没有**快捷键**和**通知**,其 **API 服务**端口由 `FLUXDOWN_BIND` 固定。

## 下载

五个标签页:**常规**、**连接**、**文件**、**高级**和**自定义分类**。

### 常规

| 设置项 | 作用 | 默认 |
|---|---|---|
| **默认保存目录** | 新下载的保存位置。 | 空 |
| **跟随上次保存位置** | 新建下载默认使用上次的保存位置。 | 关 |
| **跟随上次下载目标设备** | 在**下载到**中恢复上一次下载选择的设备,仅本设备。 | 关 |
| **记住历史保存路径** | 在**新建下载**的保存目录下拉中列出最近使用的路径。 | 开 |
| **免打扰下载** | 外部来源(如浏览器扩展)的下载直接以默认设置开始,不打开**新建下载**窗口。 | 关 |
| **免打扰时自动分类** | 免打扰模式下自动选择分类。开启免打扰后显示。 | 开 |
| **免打扰时跳过二次选择** | 跳过 BT 文件选择、画质或插件选择等后续询问。开启免打扰后显示。 | 关 |
| **默认下载队列** | 浏览器扩展和新建下载默认使用的队列。 | 空 |

### 连接

| 设置项 | 作用 | 默认 |
|---|---|---|
| **线程数量** | **自动**由下载器智能调节每个任务的连接数;**自定义**设置每任务上限。 | 自动 |
| **自动模式线程上限** | 自动模式下调度器可使用的线程上限。自动模式下显示。 | 16 |
| **多 CDN 节点并发下载(实验性)** | 同一文件同时从多个 CDN 节点 IP 下载。仅 HTTPS 直链;使用代理时自动禁用。 | 关 |
| **最大 CDN 节点数** | **自动**或**自定义**(1-8 个节点)。开启多 CDN 后显示。 | 自动 |
| **多网卡聚合下载** | 同一文件同时经多个网络适配器下载。 | 关 |
| **已学习的服务器策略** | 服务器拒绝多连接(403/429)后,引擎会记住其连接上限 24 小时;可手动清除重新学习。 | - |
| **最大同时下载数** | 同时进行的任务数,1-1024;BT/磁力任务不计入。 | 5 |
| **下载限速** / **上传限速** | 全局限速,0 表示不限制。 | 0 |
| **失败重试次数** | 瞬时错误后的自动重试次数,-1 到 20。 | 3 |
| **重试间隔** | 每次重试前等待的秒数,随重试次数递增。 | 5 |
| **启动时继续未完成的下载** | 自动继续上次关闭时仍在下载的任务。 | 关 |

线程数过高时会显示风险提示,因为许多服务器会限速或封禁开启过多连接的 IP。

### 文件

| 设置项 | 作用 | 默认 |
|---|---|---|
| **文件已存在时** | **自动重命名**、**覆盖旧文件**、**跳过下载**或**每次询问**。询问需要 FluxDown 窗口处于打开状态。 | 自动重命名 |
| **使用服务器文件时间** | 用服务器返回的时间设置文件修改时间。 | 关 |
| **下载完成后计算文件哈希** | 对完成的文件计算哈希。 | 关 |
| **哈希算法** | MD5、SHA-1、SHA-256 或 SHA-512。 | SHA-256 |
| **文件被删除或移动时** | 已完成任务的文件消失后:**保留任务记录**或**自动删除任务记录**。 | 保留 |
| **自动清理已完成记录** | **从不**、**立即**、1 / 7 / 30 天后或自定义天数。只清理任务记录,文件保留;做种任务在做种停止后才清理。 | 从不 |
| **空闲时定期检查已完成文件** | 没有下载时也定期检查已完成文件是否仍存在。关闭可避免唤醒休眠中的 NAS 或外置硬盘。 | 关 |

### 高级

- **用户代理 (User-Agent)** - 下载请求使用的浏览器标识:默认、Chrome、Edge、Firefox、Safari 或自定义。**管理预设**编辑已保存的列表。
- **文件管理器命令** - 打开文件/目录时调用的自定义命令,留空使用平台默认。
- **Aria2 高级选项** - aria2 风格选项的草稿编辑器。K/M/G 后缀按 1024 进位,`split=0` 表示自动,未填写的键保持不变;点击应用后才生效。

### 自定义分类

内置分类(视频、音频、文档、图片、程序、压缩包、其他)可以调整顺序并指定各自的保存目录。**添加分类**创建自定义分类:名称、图标、保存目录(留空使用全局默认)和匹配规则(**按扩展名**、**按网址**或**按正则表达式**)。自定义分类优先于内置分类匹配,拖动行可调整顺序。**恢复默认**还原内置分类列表,**一键分类目录**启用按分类分文件夹。也可以在侧边栏**全部**下的分类子项上右键新建或编辑分类。

## BitTorrent

五个标签页:**常规**、**连接**、**Tracker**、**做种**和**防吸血**。关闭 BitTorrent 后,**连接**、**Tracker** 和**做种**标签页会隐藏。磁力、文件选择与 Tracker 的用法见 [BitTorrent 指南](/docs/zh/protocols/bittorrent/)。

**常规** - **启用 BitTorrent**(开);新建任务的**选片方式**:**最稀有优先**(默认)或**按顺序下载**;**先下载首尾文件块**(关);**文件选择 60 秒后自动选择默认项**(开)。

**连接**:

| 分组 | 设置项(默认) |
|---|---|
| 监听 | **起始端口** / **结束端口**(首次使用时随机生成并保存固定端口;起始与结束相同即单端口)。还有一行监听状态,显示端口是否可达。修改端口需重启。 |
| 传输 | **启用 DHT**(开)、**端口映射(UPnP / NAT-PMP)**(开)、**本地节点发现(LSD)**(开)、**启用 uTP**(开)、**uTP 拥塞控制**(LEDBAT 或 CUBIC;LEDBAT)、**协议加密(MSE)**(关闭 / 启用 / 强制;启用)。 |
| 节点与数据来源 | **每个种子的上传槽数**(0 = 自动)、**HTTP 源(Web Seed)**(开)。 |
| 连接上限 | **全局最大连接数**(0 = 不限制)、**每个任务的最大连接数**(512)。 |
| I2P 匿名网络 | **启用 I2P**(关)通过本机 I2P 路由(SAM 桥)下载 `.i2p` 种子(**SAM 主机** 127.0.0.1、**SAM 端口** 7656、**混合模式** 关)。需要先运行 i2pd 等 I2P 路由。 |
| 汇报策略 | **向所有层级汇报**(开)、**向层级内的所有 Tracker 汇报**(开)。 |

**Tracker** - **Tracker 列表**(每行一个地址,添加到每个新 BT 任务,不影响已在运行的任务)和 **Tracker 订阅**(开),订阅地址的 Tracker 会与你的列表合并去重。

**做种**:

| 设置项 | 作用 | 默认 |
|---|---|---|
| **任务完成后自动做种** | 任务下载完成后自动开始做种;做种会使硬盘保持唤醒。 | 开 |
| **最大活动做种数** | 0 表示不限制,超出的已完成任务排队等待。 | 0 |
| **启动时自动继续做种** | 重启后为已完成任务继续做种(手动停止做种的任务除外)。 | 开 |
| **当总分享率达到** / **当做种后分享率达到** | 分享率上限,0 表示不启用。 | 0 |
| **达到总做种时间** / **达到不活跃做种时间** | 时间上限,单位为分钟/小时/天,0 表示不启用。 | 0 |
| **条件组合方式** | **满足任一条件**或**满足所有条件**。 | 满足任一条件 |
| **然后** | **停止做种**、**删除任务**或**删除任务和文件**。 | 停止做种 |

**防吸血** - 防吸血的设置、**封禁名单**和**事件日志**。默认开启防护,客户端名称指纹规则直接执行,其余规则默认仅观察。详见 [BT 防吸血](/docs/zh/protocols/bt-guard/)。

## 代理

**代理设置**是 HTTP、FTP、HLS、DASH 下载,以及 RSS 与插件请求使用的全局代理模式:

| 模式 | 行为 |
|---|---|
| **不使用代理** | 直接连接(设置目录中的默认值)。 |
| **系统代理** | 使用系统检测到的代理;页面显示检测结果并提供**测试连接**。 |
| **手动配置** | 使用你填写的代理。 |
| **自动(推荐)** | 直连无阻塞起飞,同时把手动代理与系统代理当作并行路径,用真实分片测速并把连接导向更快的一条;直连仍保留多 CDN 加速。 |

**手动配置**字段:**代理类型**(HTTP、HTTPS、SOCKS4、SOCKS5)、**服务器地址**、**端口**、**用户名**、**密码**、**排除列表**(逗号分隔)和**测试连接**。

页面上的其他分组:

- **BitTorrent** - **BT 使用代理**(关),可选**代理来源**(**手动代理**或**系统代理**)和**节点连接也走代理**(开)。HTTP 与 SOCKS4 代理不能转发 UDP,会停用 UDP Tracker 与 uTP;SOCKS5 没有这个限制。
- **按协议设置代理** - 为 **HTTP 与 HTTPS**、**FTP**、**HLS**、**DASH**、**BitTorrent**、**eD2K** 分别指定出口,覆盖对应协议的全局代理;任务代理和站点规则仍然优先。留空保持原有行为,填写 `direct://` 可直连。eD2K 需填 SOCKS5/5h 地址。
- **站点规则** - 为特定网站指定出口。每条规则匹配**域名**或**正则表达式**,出口可选**直连**、**系统代理**、**手动代理**或**自定义代理**。规则在所有代理模式下都生效(包括**不使用代理**和**自动**),从上到下第一条命中的规则生效。规则覆盖 HTTP/HTTPS、FTP、HLS/DASH、RSS、插件请求,以及应用更新、组件、插件包等 FluxDown 自身下载;单独指定了代理的任务与订阅、webhook 推送不受影响。**测试网址**可查看某个网址会走哪条出口。规则只保存在本设备。
- **已保存的网站凭据** - 按网站保存的 HTTP 认证凭据,仅存储在本设备,新建任务时自动套用;可逐条删除或全部清除。

状态栏中的代理选择器修改的是同一个全局模式。
